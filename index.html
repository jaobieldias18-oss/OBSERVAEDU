O localStorage guarda os dados apenas neste navegador, neste computador. Ele não é um banco de dados institucional: não oferece controle de acesso, auditoria ou compartilhamento entre máquinas.

O backup é um arquivo JSON com todos os registros e a identificação da escola. A importação substitui os dados atuais deste navegador após confirmação.

Aplicativo instalável (PWA)

Instalação, funcionamento offline e atualizações.

Verificando

O ObservaEdu pode ser instalado na tela inicial ou na área de trabalho e aberto em uma janela própria. A instalação não envia dados para servidores e não substitui o backup em JSON.

  • Android (Chrome ou Edge): abra o menu do navegador e escolha Instalar aplicativo ou Adicionar à tela inicial. O botão de instalação também aparece abaixo quando o navegador permite.
  • iPhone e iPad (Safari): toque em Compartilhar e depois em Adicionar à Tela de Início. Outros navegadores no iOS podem não oferecer essa opção.
  • Computador (Chrome ou Edge): use o ícone de instalação na barra de endereço ou o menu do navegador.
  • Offline: funciona somente depois que o site já tiver sido aberto e armazenado em cache neste navegador. A primeira visita ainda precisa de internet.
  • Atualizações: quando houver uma nova versão, o sistema avisa. Atualizar não apaga os registros salvos no localStorage.
  • Segurança: O PWA não oferece login, autenticação nem proteção institucional. Qualquer pessoa com acesso a este navegador pode consultar os dados locais.

Privacidade e segurança

Cuidados importantes ao registrar informações profissionais.

Leia com atenção
  • Registre apenas informações profissionais necessárias à observação pedagógica. Evite dados pessoais sensíveis.
  • Os registros não são enviados a serviços externos nesta versão.
  • Qualquer pessoa com acesso a este navegador e a este computador pode consultar os dados armazenados.
  • Exporte backups regularmente e guarde o arquivo em local seguro.
  • Antes de usar o sistema em produção, a escola deve definir política de acesso, retenção e proteção de dados.

Preparado para evoluir

Limites conscientes desta primeira versão.

Esta versão foi organizada em camadas simples (configuração, armazenamento, análise, relatório e interface). Uma versão institucional precisará de banco de dados, autenticação, controle de permissões, trilha de auditoria e política de backup. Nenhuma integração fictícia com servidores ou inteligência artificial foi implementada.

A análise automática usa regras explícitas de JavaScript. Para integrar uma IA no futuro, a função central de análise pode ser substituída, mantendo a revisão humana obrigatória antes da impressão.

Como usar o ObservaEdu

  1. Nova observação: preencha a identificação da aula e avance pelas etapas Introdução, Desenvolvimento e Conclusão.
  2. Respostas: marque Sim, Parcialmente, Não ou Não observado / Não se aplica. A última opção nunca é tratada como falha.
  3. Rascunho: use "Salvar rascunho" para continuar depois. O Histórico permite reabrir e editar.
  4. Análise: leia os fatos registrados, revise os textos gerados por regras e ajuste o que desejar.
  5. Relatório: clique em "Gerar relatório" para concluir. Depois use "Imprimir / Salvar em PDF" e escolha a opção do navegador.
  6. Instalação e offline: abra o site uma vez, instale pelo navegador e aguarde o aviso de nova versão quando houver. O modo offline só funciona depois desse primeiro carregamento.

Os dados desta versão ficam no armazenamento local deste navegador. Faça backup em Configurações e não use o sistema como único repositório institucional. O PWA não oferece login nem proteção institucional.

Uma nova versão do ObservaEdu está disponível. Seus registros serão mantidos.
